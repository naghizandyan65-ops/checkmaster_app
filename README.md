# مدیریت چک — نسخه اولیه (فاز ۱)

این پروژه شامل هسته اصلی نرم‌افزار مدیریت چک است:
- مدیریت اشخاص
- مدیریت صندوق و حساب‌ها
- ثبت چک دریافتی و پرداختی + تغییر وضعیت (در جریان / پاس شده / برگشتی / باطل شده)
- تبدیل چک دریافتی به چک پرداختی (در لایه داده پیاده‌سازی شده)
- داشبورد خلاصه وضعیت

ماژول‌های گروه اشخاص، اسناد انتقالی، ورود از اکسل، چاپ قالب صیاد، گزارشات، پیامک،
سال مالی و پشتیبان‌گیری در فازهای بعدی اضافه می‌شوند.

## چطور از این پروژه یک فایل APK بگیرم؟

### روش ۱ (پیشنهادی، بدون نصب چیزی) — GitHub Actions
1. یک ریپازیتوری جدید در github.com بسازید (رایگان).
2. تمام فایل‌های این پوشه را در آن ریپازیتوری push کنید.
3. به تب **Actions** بروید — یک workflow به نام «Build APK» به‌صورت خودکار اجرا می‌شود
   (چند دقیقه طول می‌کشد).
4. وقتی اجرا تمام شد، در همان صفحه Actions قسمت **Artifacts** فایل
   `cheque-manager-debug-apk` را دانلود کنید — همان فایل apk نصب‌شدنی است.

### روش ۲ — Android Studio
1. [Android Studio](https://developer.android.com/studio) را نصب کنید (رایگان).
2. از منوی File > Open، این پوشه را باز کنید.
3. صبر کنید Gradle Sync تمام شود (اینترنت لازم دارد چون وابستگی‌ها را دانلود می‌کند).
4. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
5. فایل apk در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.

## نصب روی گوشی
فایل apk را روی گوشی کپی کنید، «نصب از منابع ناشناس» را در تنظیمات فعال کنید و آن را نصب کنید.
